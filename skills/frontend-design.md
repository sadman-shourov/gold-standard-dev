# Frontend Design Skill

Create production-ready, distinctive web interfaces that don't look AI-generated.

**Source:** `anthropics/skills` — frontend-design
**Install:** `npx skills add anthropics/skills --skill frontend-design --agent claude-code`

## When to Use

- Building new UI components or pages
- "Make it look good"
- Design system decisions
- Any visual output

## Core Principles

- Bold aesthetic choices — never default to Inter + purple gradients
- Distinctive typography, creative layouts, thoughtful animations
- Production-ready HTML/CSS/JS or React components
- CSS variables, animation delays, contextual visual effects
- Commit to a specific design direction (brutalist, minimalist, maximalist, etc.)

## Anti-Patterns

- Defaulting to Inter font
- Purple/blue gradients as the default
- Generic card layouts
- Bootstrap-looking components
- AI-generated sameness
