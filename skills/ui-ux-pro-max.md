# UI/UX Pro Max Skill

Frontend UI/UX design intelligence. Activate FIRST when user requests beautiful, stunning, gorgeous, or aesthetic interfaces.

**Source:** `binjuhor/shadcn-lar` — ui-ux-pro-max
**Install:** `npx skills add binjuhor/shadcn-lar --skill ui-ux-pro-max`

## Capabilities

- **50 styles:** glassmorphism, claymorphism, minimalism, brutalism, neumorphism, bento grid, dark mode, responsive, skeuomorphism, flat design
- **21 palettes:** curated color combinations
- **50 font pairings:** typography combinations with rationale
- **20 charts:** data visualization patterns
- **8 stacks:** React, Next.js, Vue, Svelte, SwiftUI, React Native, Flutter, Tailwind

- Design review
